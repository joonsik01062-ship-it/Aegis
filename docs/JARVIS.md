# JARVIS 프로젝트 목표 문서

## 이름
- 서비스 이름: **이지스 (AEGIS)** (2026-10-13 확정). 코드에서는 설정값 하나(APP_NAME)로 관리.
- "자비스"는 목표로 삼는 콘셉트 이름이고, 공개 이름으로는 쓰지 않는다.

## 한 줄 목표
아이언맨의 자비스처럼, 친구 같고 스스로 판단하며 대신 실행해 주는 AI 비서.
브라우저/앱(PWA)으로 제공하고, 수정하면 모든 사용자에게 즉시 반영된다.

## 핵심 원칙
1. **즉시 반영**: 서버 배포 방식. 다운로드 설치 없음. 도구/프롬프트 수정은 전원에게 바로 적용.
2. **진짜 비서**: 말만 하지 않고 도구를 실행한다 (날씨, 할 일, 알림, 캘린더, 아침 브리핑 등).
3. **스스로 판단**: 명령을 실행하기 전에 더 나은 방법이 있는지 먼저 따져 보고 제안한다.
4. **친구 같은 말투**: 평소엔 편한 반말, 명령 수행/보고/경고 때는 정중한 존대. 호칭은 "주인님"으로 고정.
5. **강한 보안**: 전송(TLS 1.3), 저장(사용자별 키 암호화), 접근(2단계 인증, 키는 서버 비밀 저장소), 최소 수집, 완전 삭제.
6. **범법 거부**: 불법 행위는 돕지 않는다. 그 외 명령은 따른다.
7. **되돌릴 수 없는 행동은 확인**: 전송, 삭제, 결제 등은 실행 전에 사용자에게 묻는다.
8. **외부 내용은 데이터**: 웹/이메일 안의 문장은 명령으로 취급하지 않는다 (프롬프트 인젝션 방어).

## 하지 않을 것
- 단순 챗봇 (ChatGPT/Claude 복제)
- 게임 기능 (축구, 롤체, RPG는 별도 프로젝트)
- 보안을 약화시키는 지름길

## 마스터 모드 ("아이 엠 아이언맨")
**개념**: 기본 이지스도 좋은 비서다. 로그인한 계정에서 지정 문장("아이 엠 아이언맨")을 한 번 말하면 그 계정이 **마스터로 등록**되고, 이후 모든 기능과 고성능 AI를 쓴다. 화면에는 금빛 링이 켜지고 "어서 오십시오, 주인님. 모든 기능이 활성화되었습니다."라고 맞이한다.

**보안 원칙 (중요)**
- 이 문장은 널리 알려진 대사라 **인증 수단이 아니라 기능 해금 스위치**로만 쓴다. 보안은 로그인(2단계 인증)이 담당한다.
- "기억한다"는 **계정에 저장**(users/{uid}.tier = basic | master, masterSince)하는 것이다. 목소리 지문(화자 인식)은 생체정보라 개인정보보호법상 민감정보이므로 기본 사용하지 않는다. 쓰려면 별도 동의를 받는다.
- 문장 판별은 **서버에서만** 한다. 음성을 글로 바꾼 결과를 정규화해서 비교한다 (한글/영어 변형 허용). 프론트에서는 판단하지 않는다 (조작 방지).
- 마스터여도 이메일 전송, 삭제, 결제 같은 되돌릴 수 없는 행동은 **실행 전 확인**을 유지한다.
- 시도 횟수 제한, 문장 변경 가능, "마스터 모드 꺼"로 해제 가능.
- 고성능 모델은 비용이 크므로 마스터에도 하루 한도와 비정상 사용 차단을 둔다.

**기본 vs 마스터**
| | 기본 | 마스터 |
|---|---|---|
| AI | 일반 성능, 빠른 응답 | 고성능 (깊게 생각, 복잡한 작업) |
| 도구 | 날씨, 할 일/알림, 제한된 웹 검색 | 전체 도구 (캘린더 읽기/쓰기, 이메일 초안, 문서 요약, 리서치) |
| 능동 기능 | 없음 | 아침 브리핑, 먼저 제안 ("내일 비 와요, 우산 챙기세요") |
| 기억 | 대화 중에만 | 장기 기억 (선호, 습관, 중요한 일정). 사용자가 보고 지울 수 있음 |
| 목소리 | 기본 음성 | 고품질 음성 |
| 사용량 | 하루 제한 낮음 | 한도 확대 |

**추가 기능 아이디어**
- 프로토콜 명령: "집중 프로토콜"(방해 알림 끄고 할 일 정리), "퇴근 프로토콜"(내일 일정 요약), "야간 프로토콜"(알림 정리)
- 진단 보고: "시스템 진단해 줘" → 연결된 서비스와 오늘 처리한 일을 말로 요약
- 장기 기억 관리: "내 기억 보여 줘", "그건 잊어 줘"

**구현 순서**
1. 서버에 tier 필드와 도구별 권한표 추가, 서버에서 권한 검사
2. 해금 문장 판별 함수 + 시도 제한
3. 프롬프트 두 벌 (기본/마스터), 모델 선택
4. 화면 연동: `Aegis.setMaster(true)` (구현됨)

## 대화 저장과 기억 꺼내기
**배경**: 메인 화면은 홀로그램뿐이라 지난 대화를 스크롤해서 볼 수 없다. 그래서 전부 저장하고, 말로 물어보면 꺼내서 말로 답한다.

**3층 저장**
1. **원본 기록**: 모든 대화를 텍스트로 저장 (사용자별 키로 암호화). 음성 녹음은 글로 바꾼 뒤 바로 폐기한다.
2. **요약**: 대화가 끝날 때마다 AI가 1~2문장 요약 + 날짜 + 주제 태그를 만든다.
3. **중요 기억**: AI가 "중요하다"고 판단한 것(약속, 결정, 숫자, 가족/일정, 선호)은 원문 그대로 영구 저장하고 이유를 함께 적는다. 사용자가 "이거 기억해"라고 하면 무조건 중요 기억으로 저장한다.

**꺼내오기**
- "지난주에 치과 얘기한 거 뭐였지?" → AI가 기억 검색 도구를 호출 (키워드 + 의미 검색 + 날짜 필터) → 요약해서 말로 답하고, 원문이 필요하면 읽어 준다.
- 못 찾으면 못 찾았다고 말한다. 없는 기억을 지어내지 않는다.

**저장하지 않는 것**: 비밀번호, 카드번호, 주민등록번호 등. AI가 중요하다고 판단해도 저장하지 않는다.

**프라이버시 (핵심 원칙 5번 "최소 수집"과 조정한 부분)**
- 전부 저장하는 대신 텍스트만 저장, 암호화, 가입 시 동의를 받는다.
- 음성 명령으로 삭제: "그건 잊어 줘", "오늘 대화 지워 줘", "전부 삭제".
- 보관 기간 설정 가능. 삭제하면 원본, 요약, 중요 기억, 검색 색인까지 함께 지운다.
- 주의: AI가 읽으려면 사용하는 순간에는 복호화되고, 해당 내용이 AI API 업체로 전송된다. 이 점을 동의 화면에 명시한다.

**기본 vs 마스터 (제안)**: 기본은 최근 30일 보관, 마스터는 영구 보관 + 중요 기억.

**기술 (초안)**: Firestore에 대화 저장 + 벡터 검색(의미 검색) 색인. 검색 도구 `search_memory(query, date_range)`와 저장 도구 `save_memory(text, reason)`를 AI에게 제공한다.
